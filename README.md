# LUMERYX

Самостоятельное Android-приложение для личных коллекций фотографий и видео. Интерфейс на русском. Приложение рассчитано на работу без обязательного сервера и платных API.

## 0.4.0

В разделе «Браузер» можно открыть HTTPS-адрес, переключать вкладки, сохранять закладки и очищать список недавних страниц. После перезапуска открывается последний адрес каждой вкладки. В меню «Ссылка» доступны системное меню обмена и открытие в другом приложении. Входящая HTTPS-ссылка открывается после подтверждения.

## 0.3.0

В разделе «Облако» выберите источник и назначение через системное меню Android. Нажмите файл или папку из списка для подтверждения. При совпадении имени доступны пропуск и сохранение обеих копий. Чтобы скопировать в обратном направлении, поменяйте папки местами. Назначение должно разрешать создание файлов.

Приложение сверяет размер и SHA-256 записанного файла. При прерывании папки уже успешно записанные файлы могут остаться в назначении. Операция выполняется в текущем сеансе. Поддержка записи в каждый облачный провайдер проверяется отдельно.

## 0.2.0

В разделе «Медиатека» выберите папку через системный диалог Android. Открывайте подпапки, переключайте плитку и список, сортируйте файлы по имени, дате изменения или размеру. Открывайте фото и видео во весь экран и перелистывайте свайпом. Для фото доступно увеличение двумя пальцами. Сердце сохраняет файл в избранное выбранной папки. Папка и избранное восстанавливаются после перезапуска.

Доступ сохраняется только на чтение. Поддержка отдельных форматов зависит от декодеров Android. Персистентная очередь запланирована на следующий этап.

## Сборка

Нужны JDK 17, Android SDK Platform 36 и Build Tools 35.0.0. Минимальная версия для установки — Android 8.0 (API 26).

```sh
./gradlew :app:lintDebug :app:testDebugUnitTest :app:assembleDebug
```

В Windows используйте `gradlew.bat`. После успешной сборки APK находится в `app/build/outputs/apk/debug/app-debug.apk`. GitHub Actions загружает его как артефакт `lumeryx-debug-apk` после прохождения lint и unit-тестов. Это debug-сборка с отладочной подписью.
