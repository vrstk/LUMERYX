# История изменений

## 0.2.0

- Добавлена локальная медиатека с системным выбором папки через SAF и переходом по подпапкам.
- Добавлены плитка, список, сортировка и миниатюры фото и видео.
- Реализованы полноэкранный просмотр со свайпами, увеличение фото и воспроизведение видео через Media3.
- Room хранит выбранную папку и избранное между запусками.

## 0.1.0

- Добавлен Android-модуль на Kotlin, Compose и Material 3.
- Добавлена русскоязычная нижняя навигация по пяти разделам.
- Реализованы светлая, тёмная и системная темы с хранением выбора в DataStore.
- Добавлены начальные модели медиатеки, каталога и операций передачи.
- Настроены Gradle Wrapper и GitHub Actions для lint, JVM-тестов и debug APK.
